# World artwork

Generated with the built-in Imagegen tool. The WebP copies are used by both the title-menu cards and the in-game backdrops. Original generated images remain in the conversation workspace.

Common prompt: Use case: stylized-concept. Asset type: a single landscape game world selection thumbnail for Super Thombo, a lively computer adventure platformer. Create polished vibrant 3D cartoon game environment key art with rich lighting, clear readable silhouette at small thumbnail size, cinematic depth, highly detailed environment, playful rather than realistic. Composition: wide landscape 3:2, a clear central landmark and a visible adventurous platform route across the foreground. Fill edge to edge. No text, no letters, no logos, no border, no UI, no hero character. This is one standalone world illustration.
